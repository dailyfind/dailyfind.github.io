はじめの設定（この端末で1回だけ）

  1. GitHub の「鍵を作る」ページを開く
  2. 名前は daily-find、期限は好きな長さ（最長1年）
  3. 「Resource owner」を dailyfind にする
  4. 「Repository access」で Only select repositories → dailyfind.github.io を選ぶ
  5. 「Permissions」の Contents を Read and write にする
  6. 「Generate token」を押して、出てきた鍵（github_pat_で始まる文字）をコピーし、下に貼る
  7. 「承認待ち（pending）」と出たら、dailyfind の承認ページで自分の鍵を承認する

鍵はこの端末のブラウザの中だけに保存され、どこにも送られません（GitHub への保存のときだけ使います）。人に見せたり、スクリーンショットを撮ったりしないでください。
